# React Frontend Boilerplate

A minimal, fast, and modern boilerplate for React applications.

## Features
- React 18
- Vite built
- Minimal dependencies

## Getting Started
```bash
npm install
npm run dev
```

## Contributing
Contributions are welcome! Please open an issue before creating a pull request.
